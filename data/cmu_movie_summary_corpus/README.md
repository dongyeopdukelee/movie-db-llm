# CMU Movie Summary Corpus

`MovieSummaries/` is an extracted, unmodified copy of the CMU Movie Summary
Corpus.

- Source: <https://www.cs.cmu.edu/~ark/personas/>
- Dataset authors: David Bamman, Brendan O'Connor, and Noah A. Smith.
- Downloaded: 2026-09-04.
- Source archive SHA-256:
  `6c3bd3d42046c4b87e2267f2e2599ba6f651b8ad23a8998237c3d2bb338ac559`
- License: [CC BY-SA 3.0 US](https://creativecommons.org/licenses/by-sa/3.0/us/).

The corpus includes movie plot summaries extracted from the 2012 English
Wikipedia dump and aligned movie metadata extracted from Freebase. Preserve
this attribution and license information when distributing these source files
or derivative dataset files.
